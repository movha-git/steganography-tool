Steganography Tool

A cybersecurity tool that hides secret messages inside images
using LSB (Least Significant Bit) steganography.

What it does
- Hide any secret text message inside a PNG, JPG, or BMP image
- The image looks completely identical to the human eye
- Extract hidden messages from encoded images
- Works offline — no internet connection required

Technologies Used
- Python 3
- Flask (backend server)
- Pillow (image processing)
- HTML, CSS, JavaScript (frontend)

How to Run
1. Install requirements:
   pip install flask flask-cors Pillow
2. Start the server:
   python app.py
3. Open static/index.html in your browser

CyberSecurity Concepts Demonstrated
- LSB Steganography
- Image pixel manipulation
- Data hiding and digital forensics
- REST API design
